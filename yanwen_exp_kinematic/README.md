# Analytical Pose-Feedback Kinematic Planner for Kinova Gen3

This repository provides the corrected implementation of the analytical pose-feedback kinematic planner used for Kinova Gen3 experiments and Isaac Lab visualization.

The package is released to clarify and correct an implementation issue in the earlier version of the code: the previous implementation used a small-attitude-error approximation and directly treated the geometric angular-velocity error as the derivative of the axis-angle attitude error. This approximation is acceptable only for short-range attitude motions. For long-range cockpit operation, the pose-feedback planner should use the analytical pose-error kinematics and the analytical Jacobian.

## What Was Corrected

The earlier code used the simplified relation

```text
phi_dot ≈ omega_e - omega_ed
```

and directly used the geometric Jacobian `J_m` for the pose-error feedback loop. However, when the attitude error is represented by an axis-angle vector,

```text
phi = log(R_err)
```

the derivative of the axis-angle attitude error is not generally equal to the geometric angular-velocity error.

The corrected attitude-error dynamics are

```text
R_err = R_e R_ed^T
phi_dot = J_l^{-1}(phi) (omega_e - R_err omega_ed)
```

where `J_l^{-1}(phi)` is the inverse left Jacobian of SO(3). Therefore, the planner uses the analytical Jacobian

```text
J_a = diag(I, J_l^{-1}(phi)) J_m
```

instead of directly using the geometric Jacobian `J_m` in the pose-error coordinate.

This correction makes the implementation consistent with the revised theoretical formulation in the paper.

## Main Conventions

The following conventions are used throughout the code:

```text
Position error:     e_p = p_e - p_ed
Attitude error:     R_err = R_e R_ed^T
Axis-angle error:   phi = log(R_err)
Analytical Jacobian: J_a = diag(I, J_l^{-1}(phi)) J_m
Euler convention:   fixed ZYX, stored as [Z, Y, X]
```

The planned joint trajectory generated by the pose-feedback planner is denoted as

```text
theta_p, theta_dot_p, theta_ddot_p
```

The joint tracking controller should track `theta_p`, not the original desired joint variable from the older implementation.

## Isaac Lab Kinova Gen3 Video

The Isaac Lab video replays the same trajectory generated by the offline planner:

```text
data/offline_planner_trace.npz
```

The Isaac visualization is not driven by random or decorative joint commands. It uses the planned joint trajectory generated by the analytical pose-feedback planner.

A typical command is:

```bash
cd <IsaacLab_root>
./isaaclab.sh -p <repo_root>/isaac/source_isaac_sim/record_kinova_gen3_video.py \
  --headless --enable_cameras --pre-roll 2 --fps 24 --width 960 --height 540 --crf 31
```

Optional camera adjustment:

## Important Implementation Notes

1. The pose error is defined as

```text
e_p = p_e - p_ed
R_err = R_e R_ed^T
```

2. The attitude-error derivative is computed as

```text
phi_dot = J_l^{-1}(phi) (omega_e - R_err omega_ed)
```

3. The analytical Jacobian is computed as

```text
J_a = diag(I, J_l^{-1}(phi)) J_m
```

4. The pose-feedback planner outputs the planned joint command

```text
theta_p, theta_dot_p, theta_ddot_p
```

5. The downstream joint tracking controller should use

```text
e_1 = theta - theta_p
e_2 = theta_dot - theta_dot_p - theta_dot_c
```

rather than tracking the older desired joint variable directly.

6. Near singular configurations, a damped least-squares inverse is recommended:

```text
J_a# = J_a^T (J_a J_a^T + lambda^2 I)^(-1)
```

## Difference From the Previous Release

The previous implementation was based on a small-attitude-error approximation. It was suitable for short-distance Cartesian motion but was not fully consistent with the revised long-range cockpit HRI formulation.

This corrected package updates the planner to use the analytical pose-error coordinate, the inverse left Jacobian of SO(3), and the analytical Jacobian. The Isaac and real-robot demos should therefore be interpreted as corrected experiments corresponding to the revised theoretical model.
